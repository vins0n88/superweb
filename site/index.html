SuperWeb 不靠截圖猜按鈕。它先把網頁讀成一份有編號的結構清單，再照你批准的計畫逐步操作：擷取表格、比價、批量填表、研究整理，每一步都看得到、停得下來、查得到紀錄。

一個任務，四個你看得見的步驟

  1. 讀結構

    把頁面讀成編號清單和可引用的段落【§n】，回答時附上原文位置，點一下就跳過去。

  2. 提計畫

    動手前先列出步驟，寫明要點哪個按鈕、在哪個欄位輸入什麼。你可以修改、批准或取消。

  3. 逐步執行

    會改動頁面的動作都先問你。隨時可以暫停、自己接手操作，再讓它繼續。

  4. 自我驗證

    結束前重新檢查實際結果並逐項回報。填表會逐欄對照你的資料，漏了哪筆就補做或列出來。

常用工作，直接套用

十個內建範本，填幾個欄位就能開始；結果是可複製、可下載 CSV 的表格。

  • 比價多個網站同一商品的價格、庫存、運費
  • 擷取頁面表格表格或結構化資料轉成 CSV
  • 多頁清單擷取沿著網站的「下一頁」翻頁收集
  • 主題研究多個來源整理成附引用的報告
  • 批量填表貼上 CSV，逐筆填寫並送出
  • 頁面摘要重點附原文段落，可點擊跳轉
  • 翻譯整頁或選定區塊翻成你的語言
  • 搜尋彙整搜尋、打開結果、整理成表
  • 聯絡資訊找出網站公開的信箱、電話、地址
  • 價格檢查和目標價比對，由程式判斷是否達標

背景任務

任務在獨立分頁跑，最多同時三個；你繼續瀏覽，完成或需要批准時跳系統通知。

排程監控

每天或每週自動執行，只有結果真的變了才通知你，例如降價或補貨。

錄製技能

自己操作一遍存成技能，下次換個參數一鍵重播。

跨分頁比較

勾選幾個打開的分頁，直接產生比較表。

匯出

結果一鍵送到 Google Sheets 或 Notion。

MCP 伺服器

Claude Code 等外部 AI 可透過 MCP 操控 SuperWeb，套用同一套安全規則。

每個動作都要過安全閘門

網頁上的文字只是資料，不是指令。SuperWeb 在每次點擊、輸入、跳轉前檢查十二條規則，被擋下或需要確認的動作都寫進稽核日誌。

  • S3只在任務相關的網域內操作
  • S4阻擋把頁面資料夾帶到外部網址或跨網域表單
  • S5銀行、支付等敏感網站分級處理
  • S6付款、刪除、送出等高風險動作一律單獨確認
  • S8不輸入卡號、身分證號、密碼、API key
  • S10每一步、每次批准與阻擋都寫進稽核日誌

第一次開啟

目前版本尚未經 Apple 公證。打開時若出現無法驗證開發者的提示，到「系統設定 → 隱私權與安全性」按「強制打開」。

模型設定

在設定中選擇 Claude、OpenAI 或 OpenAI 相容服務並填入 API key；或安裝 Ollama 使用本機模型，資料不出你的電腦。正式工作建議使用 Claude。
