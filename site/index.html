瀏覽器和你的 AI 同事一起工作

SuperWeb 和 SuperAI 互相調用。SuperWeb 負責上網、讀頁、擷取和操作；SuperAI 的專家負責分析、寫報告、存進你的文件庫。哪一邊起頭都可以。

  • SuperAI 的專家可以把整個瀏覽任務交給 SuperWeb，拿回表格與驗證結果
  • SuperWeb 交給 SuperAI 的每一筆資料都先經你批准，任務照常出現在 SuperAI 的任務列表
  • 兩個 App 都在你的電腦上，透過本機 MCP 連接
  • 也能把工作交給你自己架的賈維斯 Jarvis 2.0，同樣先經你批准

你的資料，你作主

可以接 Claude、OpenAI 或任何 OpenAI 相容服務，也可以用 Ollama 在本機跑模型，頁面內容完全不離開你的電腦。不管用哪種模型，每個動作都先過安全閘門。

  • S3只在任務相關的網域內操作
  • S4擋下把頁面資料夾帶到外部網址或跨網域表單
  • S5銀行、支付等敏感網站另外分級
  • S6付款、刪除、送出一律單獨確認，不能一次全允許
  • S8不輸入卡號、身分證號、密碼與 API key
  • S10每一步、每次批准與阻擋都寫進稽核日誌
