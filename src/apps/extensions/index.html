🧩 擴充：MCP 服務與技能

新增或變更後，在 AI 面板按「New chat」開新對話就會生效。

MCP 服務

接上 MCP 伺服器後，AI 就能使用它的工具（例如 GitHub、Notion、資料庫、本機檔案）。使用外部工具前都會先問你（伺服器標示為唯讀的工具除外），工具回傳的內容一律當成資料，不會當成指令。

技能

技能是寫給 AI 的作業說明：遇到相關任務時，AI 會先讀技能再照著做。格式與 Claude、SuperAI 的 SKILL.md 相容。

新增 MCP 服務

本機指令會以你的帳號權限在這台電腦執行，只加入你信任的伺服器。

標頭與環境變數會加密存在系統鑰匙圈。
